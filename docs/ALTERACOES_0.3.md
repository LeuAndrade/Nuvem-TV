# BXbox Cloud TV 0.3.0

- Visual inspirado na imagem fornecida: menu lateral, destaque estático, verde de foco e superfícies escuras.
- Layout aplicado ao catálogo, pesquisa, histórico, favoritos, detalhes, configurações e ajuda.
- Opção pública de Client ID removida; identificação interna, autenticação e cofre preservados.
- Foco explícito nos jogos, com contorno acima da imagem e caminho direto dos filtros à grade.
- Filtros e escolhas de configurações com diálogos focáveis; restauração de foco após fechar.
- Todas as configurações de streaming, servidor, diagnóstico, perfil leve, estatísticas, licenças e saída da conta preservadas.
- Miniaturas limitadas; destaque de até 640×360 dentro do mesmo cache de 3 MiB. Sem animações contínuas.
- Código de streaming e controle preservado byte a byte.
- Workflow corrigido do GitHub incluído na entrega.
